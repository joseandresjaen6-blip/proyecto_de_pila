 - Presentación

El presente proyecto consiste en desarrollar un juego de cartas
utilizando una estructura de datos tipo "Pila (Stack)".

La aplicación permite almacenar cartas una encima de otra y realizar
diferentes operaciones sobre ellas. Debido al funcionamiento de una pila,
la última carta agregada será la primera carta que podrá ser retirada.

Para la implementación se utiliza el lenguaje de programación "Python"
y la estructura 'deque', que permite administrar los elementos de la pila
de manera eficiente.
